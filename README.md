# boki-app-promptと解説

📚 ストーリー仕訳簿記学習Webアプリ (Boki Story App)
好みの世界観（サイバーパンク、ファンタジー、海賊など）に合わせて画面テーマを着せ替え、AIで作ったオリジナルストーリー問題を流し込んで学習できるWebアプリです。  


🚀 使い方
本アプリは、画面下部（または管理メニュー）から以下の2つのデータを自由に取り込んでカスタマイズできます。
1. テーマ設定（見た目・配色・フォント）
2. ステージ別問題データ（ストーリー仕訳問題）
お好きなAI（ChatGPT、Geminiなど）に下記のプロンプトを貼り付けて出力されたJSONを、アプリの各取り込み窓にペーストしてください。  
🎨 1.「テーマ設定」生成用プロンプト
アプリの見た目や配色を一括で変更するプロンプトです。生成されたJSONを 「🎨 テーマ設定を取り込む」 窓に貼り付けてください。

あなたは簿記教育WebアプリのUIデザイナーです。
指定された世界観に合わせて、アプリの外観テーマ定義用JSONを出力してください。

【希望のテーマ・世界観】
（例：サイバーパンク / 世紀末荒野 / 魔法学園購買部 / 江戸の大福帳 / アイドル事務所 / 深海探索）
※ここにテーマを記入

【厳格な構文ルール】
・出力は全体を { で開始し、} で終了する単一のJSONオブジェクトのみとすること。
・前置きの挨拶、解説文、Markdownコードブロック記号は一切含めないこと。
・プロパティ名および文字列は必ず半角ダブルクォーテーション " で囲むこと。

【出力フォーマット】
{
  "appTitle": "世界観に合わせたタイトル",
  "appLogo": "世界観を表す絵文字1つ",
  "submitBtnText": "判定ボタンの文言（例: 実行する、記帳する等）",
  "storagePrefix": "boki_custom",
  "fontUrl": "",
  "fontTitle": "sans-serif",
  "fontMain": "sans-serif",
  "risingSymbols": ["正解時に", "舞い上がる", "絵文字を", "4〜6個"],
  "colors": {
    "--primary": "#メイン色",
    "--primary-hover": "#ホバー色",
    "--bg-body": "#背景色",
    "--card-bg": "#カード背景色",
    "--text-main": "#基本文字色",
    "--text-muted": "#薄い文字色",
    "--border": "#枠線色",
    "--debit-border": "#借方の枠色",
    "--credit-border": "#貸方の枠色",
    "--correct-bg": "#正解時の背景色",
    "--correct-text": "#正解時の文字色",
    "--wrong-bg": "#不正解時の背景色",
    "--wrong-text": "#不正解時の文字色"
  }
}

📝 2.「お試し用：単一ステージ問題」生成用プロンプト
特定ステージ用の問題を差し替えるお試し用プロンプトです。生成されたJSONを 「追加問題データを取り込む」 窓に貼り付けてください。  

あなたは簿記教育の教材作成者です。
Webアプリの「特定ステージ用問題取り込み窓」に貼り付ける、ストーリー仕立ての簿記仕訳問題データ（単一ステージ用のJSON配列）を作成してください。

【希望の世界観・テーマ】
（例：中世の鍛冶屋ギルド / 宇宙ステーションの資材調達）
※ここに具体的なシチュエーションや登場人物、テーマを記入

【作成条件】
1. 問題数：2〜3問
2. 難易度：日商簿記3級レベル
3. 問題文の末尾には、使用する勘定科目を括弧書きで明記すること（例: （仕入）（現金））。
4. 各問題の借方合計金額と貸方合計金額は必ず一致させること。
5. 解説文（explanation）では、重要な会計用語に対応する英単語（Asset, Liability, Expense 等）を必ず併記すること。

【厳格な構文ルール】
・出力は全体を [ で開始し、] で終了する単一のJSON配列のみを出力すること。
・前置きの挨拶、解説、Markdownコードブロック記号は一切含めないこと。
・プロパティ名および文字列は必ず半角ダブルクォーテーション " で囲むこと。
・金額（amount）にはカンマを含めず、半角数字のみで記述すること。

【出力フォーマット】
[
  {
    "story": "問題文。（勘定科目1）（勘定科目2）",
    "debit": [
      { "account": "借方勘定科目", "amount": 100000 }
    ],
    "credit": [
      { "account": "貸方勘定科目", "amount": 100000 }
    ],
    "explanation": "仕訳の根拠となる解説。英語表記（Asset, Liability等）を含めること。"
  }
]  

🎁 【さらに高度にカスタマイズしたい方へ】全5ステージ一括パックについて
アプリ内の 「📦 全ステージ問題一括取り込み」 を使って、Stage 1からStage 5までが一連の壮大なストーリーで展開する「全5ステージ（計10〜20問）一括マスタープロンプト」や、コピペですぐ遊べる完成版シナリオパックは、noteにて公開・販売しています。
 Stage 1から5まで連続して物語が進行する長編RPG風プロンプト
 複合仕訳や決算整理（減価償却・引当金）を自然に学習できるシナリオ設計
 コピペで即遊べる完成版シナリオデータ（海賊編、ファンタジー編など）
